# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Technical recruiters, engineering hiring managers, software architects, and AI/ML tech leads seeking an engineer with demonstrable, empirically benchmarked production skills in AI/ML systems, data engineering, and full-stack software development.

## Product Purpose
Deliver an immersive, high-signal engineering portfolio for Mevin Jose that demonstrates rigorous engineering craft, empirical benchmark proofs (Zenodo DOI research preprints, high-throughput streaming systems, statistical forecasting pipelines), and interactive UI excellence without superficial vibe-coding cliches.

## Positioning
An engineer who treats machine learning as production software engineering: benchmark-backed, validated with statistical confidence intervals, monitored for drift (PSI), concurrency-tested against real databases, and architected for high throughput with zero data leakage.

## Operating Context
Evaluated on modern desktop displays and mobile viewports by engineering teams reviewing resumes, GitHub codebases, research preprints, and live production deployments.

## Capabilities and Constraints
- Fast interactive single-page application built on Vite, React 18, TypeScript, Tailwind CSS, Motion/Framer Motion, and Lenis smooth scrolling.
- Showcase 10+ projects categorized across AI/ML, Data Analysis, and Web Development.
- Live engineering statistics and real benchmarks directly inspectable.
- Fast, accessible navigation with keyboard focus management and smooth spring micro-interactions.

## Brand Commitments
- Deep obsidian and slate tones (`#020617`, `#0f172a`), refined border highlights (`border-white/10`), subtle cyan and electric blue accents, and purposeful motion.
- Avoid overused AI gradients, purple glow halnos, ungrounded metrics, or generic boilerplate text.

## Evidence on Hand
- UnderdogAI: 553 req/s at 50 concurrent clients, Kafka streaming, Monte Carlo 63K match simulations, 120K record Airflow/dbt pipeline.
- AI Data Analyst Agent Research Preprint: 73.40% result equivalence on 500 queries, 100% SQL execution success, Zenodo DOI: 10.5281/zenodo.22024528.
- Demand Forecasting ML System: 58.3M historical records, LightGBM, expanding-window validation, PSI drift detection.
- Adaptive Golf Alliance Foundation: production React web application deployed at adaptivegolfalliance.com.

## Product Principles
1. **Empirical Evidence Over Claims**: Let the code, architectures, and benchmarks speak.
2. **Deterministic, Accessible Interactions**: Micro-interactions must feel instant, natural, and never lock the layout engine.
3. **Restraint Over Clutter**: Choose disciplined typography and hierarchy over decorative AI halos.
4. **Performance by Default**: Zero layout thrashing, explicit media dimensions, and compositor-friendly transforms.
